# Changelog

## 0.1.0 - 2026-07-28

Initial release.

### Added
- `histogram()`: polished histogram for a single numeric DataFrame column, with optional mean/median reference lines.
- `correlation()`: polished correlation heatmap for a DataFrame's numeric columns, supporting Pearson, Spearman, and Kendall methods.
- Shared Brazil-inspired visual styling and color palette.
- Input validation with clear, actionable error messages.
- Test suite covering both visualization functions.
- Example script and dataset.
